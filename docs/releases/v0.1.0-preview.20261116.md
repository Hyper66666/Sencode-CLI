# Windows x64 preview fixes: 2026-11-16

This preview fixes media selections and remembered model/permission choices.

- Adjacent quoted paths followed by task text now become actual attachments;
  the task text is retained. Mixed video and image selections no longer silently
  turn valid images into plain paths.
- Local video can supply three timestamped frames through Windows system
  decoders. H.264 MP4 is verified, no FFmpeg installation is needed, and audio
  is not analyzed. The selected model must support image input.
- Recoverable old native execution records no longer block model and permission
  preference saves. Genuine active execution, pending cleanup and unknown tools
  retain their existing protection. Busy preference writes remain pending.

Download `install-sencode.ps1` from this release and run:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install-sencode.ps1
```

Close existing CLI windows and start `sen` again after updating. Current aliases
are unchanged. The application reports `0.1.0-dev.0`; the dated preview tag and
checksums identify the exact build. No account or conversation reset is required.

Same-candidate Windows verification: 33 model/scroll checks, 28 permission/session
checks, and 27 fullscreen checks including the real five-image request. Native
image encoders, three protocols, video PNG colours/timestamps, invalid inputs,
source preservation, decoder timeouts, and installation/upgrade/rollback are
covered by the linked release evidence. These are synthetic-provider/development-
host results; live paid providers and fresh-VM qualification remain separate.

The generic system video adapter source is available on
[Sengoo's video-frame-adapter branch](https://github.com/Hyper66666/Sengoo/tree/codex/video-frame-adapter/packages/sgmedia).
Successful sampled frames remain in system TEMP for image history, as documented
in the CLI README; video sampling is sparse and waits for bounded decoding.
