# Windows x64 preview: 2026-11-13

Download `install-sencode.ps1` from the GitHub Release and run:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install-sencode.ps1
sen
```

The script installs into `%LOCALAPPDATA%\SencodeCLI` without administrator
access. `-Prefix C:\tools\SencodeCLI -NoPath` selects a portable installation.
The ZIP can also be extracted and its `install.ps1` run directly. Existing
installations should be closed before upgrading. See [installation](../installation.md)
for PATH, rollback, isolated databases and shared-state schema 29.

## Contents and provenance

This release distributes the unchanged, previously verified `candidate-6`
archive. The application reports `sencode 0.1.0-dev.0 (Sengoo native)`.
The archive includes `sen`, `sencode`, the command forwarder, ripgrep 14.1.1,
Codex app-server 0.144.4, Sencode ACP 0.2.102, its required native runtime DLL
and upstream notices. The configuration companion is distributed separately.

- Application SHA-256: `0288b51b0626aca61b7d2e4b50ad08b767278eae55b6d62270a0764eb35ce7c2`.
- Original build base: `c603b84022bb3afeec4f3fb217dd016abd48f028` plus the

## Verification scope

The original candidate passed nine native suites and eleven product suites,
including 25 fullscreen checks. Before publication, all 274 source records in
each of those two reports were rehashed against the current checkouts with no
differences. The ZIP, every payload and the original installer were verified.

The release bootstrap is checked with Windows PowerShell 5.1: installation to
a fresh Unicode prefix, matching application bytes, `--version`, preserved
offline ZIP and corrupted-archive rejection before installation. The existing
package smoke covers isolated installation, upgrades, rollback, command lookup,
Unicode arguments, startup and unchanged PATH. See the release's
`release-evidence.json` for terminal results and asset identities.

These checks use the Windows development host and synthetic providers.
Fresh-VM installation, paid-provider availability, Linux/macOS and code signing
are outside this development preview's qualification.
