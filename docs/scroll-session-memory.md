# 会话选择记忆与滚动

`sen -c`、`sen -r`、`sen resume` 和 `/resume` 恢复会话时，沿用该会话上次
选中的供应商、模型和思考强度。在 `/model` 完成选择后，即使不再发送消息，
退出后仍可恢复。全局默认模型继续供新会话使用。

启动参数优先级：`--connection` 替换保存的整组选择；单独的 `--model` 使用
保存的供应商并重置思考强度；`--effort` 覆盖思考强度。切换会话和分支保留
各自的选择。旧会话回退到原有模型字段，未记录的思考强度使用其正常默认值。

执行中选择其他模型，只影响下一轮。选择在当前执行与工具清理完成后保存。
保存使用现有会话锁和 SQLite 事务，只增补 `shared_modes.cli_target` 及兼容
模型字段，保留 Plan/Goal、用量和权限边界。保存失败会显示提示。

供应商移除或已保存的能力不再可用时，界面标明 `unavailable`，可通过
`/model` 重选；请求失败时不会静默转发给默认供应商。项目的 `.sencode`
携带经过白名单校验的选择元数据，支持目录改名和显式历史导入，不携带密钥。

手动审批、自动审批和完全权限也按会话记忆。`Shift+Tab` 或 `/permissions`
选择后不必再发消息；恢复会话时，输入框下方显示上次的权限。执行中的切换
只影响下一轮，当前请求和已弹出的审批保持原策略，清理完成后再保存。
`--permissions manual|auto|full` 可显式覆盖记忆；`--auto-edit` 覆盖为自动编辑，
`--allow-commands` 追加命令授权。规划模式独立，不因权限切换而批准执行。
新会话及没有权限记录的旧会话使用手动审批。目录改名不影响本机会话的记忆；
独立导入的历史不会授予文件、命令或 MCP 权限。

一轮用户消息后的文本、工具、子代理和后续回答共用一个 `SENCODE` 标题。
恢复与调整窗口宽度保持相同分组，工具仍保留各自的状态和展开位置。

滚轮和触控板的小幅输入按行累积，连续滚动最多每 16 ms 合并刷新一次；
普通按键、取消、resize 和审批仍优先处理。滚动区域的重叠文字、颜色及样式
全部匹配时，Sengoo 渲染器复用已有屏幕行，仅刷新新进入的行。弹窗、布局
或内容不匹配时回退逐行刷新。最上方保留完整一页，不再滚成仅剩一行的空屏。
输入框位置固定，空白时不显示预设文字，空闲不持续重绘。

验证入口为 `scripts/test.ps1 -Cases tui_scroll,session_target,scroll_target`；
权限记忆、子代理等待与对话分组使用
`-Cases scheduler,session_permissions,tui_turns,tui_timeline,engine,session_policy_wait`。
原生测试覆盖 80/120/160 列、有色/无色、焦点及恢复规则；真实控制台夹具
另行检查屏幕单元格、滚轮延迟及实际 loopback 请求路由，不调用付费服务。

权限记忆、子代理等待和对话分组的候选版本及安装证据见
[本轮验证记录](permission-session-verification.md)。
