# Read-only projection
The view uses allowlisted shared connection metadata and current AgentOptions.
It labels the explicit CLI target versus shared default or sole connection;
permissions come from the effective local policy. Raw config JSON and environment
enumeration never enter the view. Doctor reports credential availability as a
boolean and validates packaged managed runtime metadata; it never logs key values,
starts a model or reads official auth files. Memory displays the same bounded,
layered AGENTS.md/CLAUDE.md content used for context and explicitly labels learned
memory unavailable. These commands are enabled only by the implemented fullscreen
host. No SQLite migration or data writes are introduced by these views.
