## Why

Completed children and large tool outputs repeatedly enter the model context in
full even though the durable ledger already retains the original evidence.
A model's claim that checks passed also needs a visible distinction from host
verification. The user authorized implementing the staged Sengoo-native plan.

## Capabilities and ownership

The single owner `cli-agent-evidence` covers report validation, session-scoped
immutable evidence references, bounded reads and model-context projection.
Implementation is Sengoo under `src/`; existing state owns the source evidence.
Public transcripts, tool ledger values, provider attribution and events retain
their original content. No shared-state schema or native ABI change is required.

## Non-Goals

No durable Task/Attempt inbox, new scheduler, background job protocol, automatic
worktrees, external event intake, vector memory or independent spill database.
Reports never complete Goals, approve tools or authorize retries. This change
does not recover bytes discarded by existing command capture limits.
